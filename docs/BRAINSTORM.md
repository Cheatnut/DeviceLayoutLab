# 首轮讨论：器件、版图与电路的联动教学

日期：2026-09-29。状态：讨论草案，未经技术方案批准。

后续状态：用户已确认 Blender + Three.js 与首轮基础案例，明确暂不做空间电场求解，并将重心调整为后端物理实现与工艺库教学。当前范围和新方案见 `PLAN.md`；本文保留首轮讨论，不作为正式实施授权。

## 1. 已确认需求

1. 项目独立，不连接既有 RTL-to-GDS 平台；可复用 ORFS 或其它设施。
2. 首要目标是看懂标准单元内部，首先用于课堂和教学演示。
3. 必须使用可编辑的建模软件，网页支持实时控制、预览和探索。
4. 覆盖平面 MOS、FinFET、GAA 三种结构。
5. 区分教学理想模型与工艺/单元库约束模型。
6. 最终打通器件结构、二维版图、三维空间、电路拓扑与电气行为。

CMOS 描述互补电路构成，平面 MOS、FinFET、GAA 描述器件结构，不能作为互斥概念。平面 MOS 可用于建立基础知识，不应统一称三者为先进节点。

## 2. 建议的课堂体验

同一标准单元同步呈现：晶体管级原理图、二维版图、三维模型，以及电压/电流曲线。选中任一对象，在其它视图中定位同一对象。

以反相器为第一条完整案例：

1. 识别 NMOS/PMOS 的源、漏、栅、体及适用的偏置关系。
2. 旋转模型、切开栅极截面，观察结构；切换平面、鳍式与纳米片教学器件。
3. 调节输入电压，结合计算模型观察导通、输出电压与负载充放电。
4. 切换为二维俯视图，识别层图形、端子、接触和互连。
5. 在已核验的库单元上比较实际晶体管数量、共享区域、引脚和布线。

NAND2、NOR2、传输门、MUX、触发器是后续候选；首批数量待确认。逻辑门的最简教学电路与实际库单元实现可能不同，必须分别说明。

## 3. 三维重建的可行性边界

GDS/OASIS 提供分层二维几何及层次，不等于成品三维几何。LEF 是后端抽象，Liberty 是行为/时序等抽象，SPICE/Verilog-A 是电气模型；没有任一文件能够独立包办三维重建。

| 信息 | 可支持的工作 | 仍需补充的内容 |
| --- | --- | --- |
| 单元 GDS/OASIS | 平面轮廓、层、重复结构 | 图层含义及其工艺变换 |
| 工艺栈、ITF/提取资料 | 金属与介质高度、厚度等 | 器件内部结构未必包含 |
| 器件规则、PCell、文献 | 栅、沟道、鳍/纳米片尺寸与构造线索 | 加工后的形貌及来源核验 |
| 网表与 LVS/提取映射 | 器件、端子、网络与几何关联 | 适配具体 PDK 的提取规则 |
| 紧凑模型 | 端口电气行为 | 通常不是三维空间场求解 |

建议采用两条入口，共用语义对象与交互系统：

- 教学模型：参数化的三类结构，可自由探索；尺寸与物理行为明确写出教学假设。
- 工艺约束模型：读取已支持的 PDK/库单元，用核验的几何、连接和层叠资料重建；缺失值标明假设或不可用。

还应分别标注几何来源与电气来源。例如真实单元 GDS 加教学层厚度，只能称带假设的单元三维重建。

生产制造涉及沉积、刻蚀、填充、外延、平坦化等过程；简单逐层挤出适合部分互连展示，不能自动生成准确的 FinFET/GAA。KLayout XSection 展示了使用过程脚本结合掩膜生成截面的思路，但它本身不是完整三维工艺求解器。

参考：[KLayout XSection 脚本说明](https://klayoutmatthias.github.io/xsection/DocIntro.html)、[SKY130 工艺假设](https://skywater-pdk.readthedocs.io/en/main/rules/assumptions.html)。

## 5. 建模与网页技术候选

建议讨论 Blender Python/Geometry Nodes + glTF/GLB + Three.js：

- Blender 用于编辑、程序化构造、模型核验、模型源文件与教师导出视频。
- GLB 携带展示几何和基础场景；语义 ID/元数据连接二维版图、电路与三维部件。
- Three.js 承担浏览器相机、选取、剖切、透明/隔离、参数界面和教学动态效果。
- 网页电气行为来自独立计算或仿真模块；实时交互可以使用核验的预计算数据，不必每帧启动模拟器。

Blender 工程不是网页可直接执行的建模应用。Geometry Nodes、约束和着色逻辑也不会因 GLB 导出而完整迁移。连续参数可由浏览器程序化几何处理或由建模服务重建，增减鳍/片数量等拓扑变化要重新生成。两端应共享参数定义，防止模型漂移。

我可以编写参数化建模脚本、部件语义、相机/剖切脚本和浏览器交互代码；物理准确性仍以来源、模型和核验结果为依据。

其它候选包括 FreeCAD/CadQuery（尺寸与实体运算）及 Babylon.js（浏览器引擎）；目前没有确定引入。也没有安装任何软件。

参考：[Blender glTF 导出说明](https://docs.blender.org/manual/en/latest/addons/import_export/scene_gltf2.html)、[glTF 标准](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)、[Three.js](https://threejs.org/docs/)。

## 6. 物理过程应分层解释

1. 结构层：空间位置、材料、沟道与栅极控制关系。
2. 教学行为层：明确假设的开关/简化 MOS 行为、节点充放电。
3. 电路仿真层：适配紧凑模型的 DC/transient 分析，观察端口电压电流。
4. 可选器件物理层：TCAD 或经核验的求解数据，展示空间电势/载流子等分布。

紧凑模型输出不应被包装成三维电场或载流子分布。粒子轨迹只能作为说明性动画，约定电流与电子运动方向须区分；逻辑输出变化应与负载充放电关联，不能仅用输入超过阈值后瞬间翻转来覆盖全部教学。

跨结构比较时固定比较问题与条件，不直接用不同节点、VDD、尺寸和负载的结果声称某种结构性能更高。

## 7. 二维与三维的分工

集成电路版图通常以各层二维投影记录，器件与多层互连存在实际三维结构。三维特别适合解释栅包围沟道、接触/过孔、层间连接和剖面；整芯片三维会产生遮挡与性能负担。

建议缩放策略：整块设计默认二维；选中单元或网络后进入局部三维；器件微观结构按需展开。原始数据与教学放大分离。

提高可读性的候选交互：

- 图层开关、相关层自动筛选和背景淡化。
- 网络着色与材料着色分别提供，避免混用颜色含义。
- 选中端子后沿已提取的连接追踪，而非将二维重叠当作导通。
- 剖切面同步绘制二维切线，提供正交俯视、截面和透视。
- 爆炸视图保留位置参照线，显示教学间距与放大倍率。
- 按器件、单元和局部互连控制细节等级，避免一次加载全部细节。

| 教师镜头与实验书签 | 保存相机、剖切、输入和解释状态供课堂复现 |
