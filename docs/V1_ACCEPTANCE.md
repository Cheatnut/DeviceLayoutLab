## 1. 首版用户路径

打开桌面 Chrome/Edge -> 访问现有 Linux 服务器上的教学网页 -> 默认打开几行单元的编排教学场景 -> 二维/三维上下排列查看 -> 选中单元/引脚/网络，联动资料与局部结构 -> 展示性拆解/剖切 -> 切换真实 SKY130 数据通路案例 -> 查看已有阶段和参数对照 -> 修改允许参数并点击运行 -> 等待 ORFS，查看本次结果及前后变化。

此路径中的“编排教学场景”“真实 ORFS 结果”和“展示性拆解”始终有明确来源和状态。首版没有答题、测验、评分、自定义设计上传或故障编辑。
