# 首版验收草案与产品取舍

方案日期：2026-09-29；实施状态更新：2026-10-06。状态：用户已授权开发，工作台骨架、单一配置和首批真实工艺库读取已实现并验证；完整首版尚未验收。

## 1. 首版用户路径

打开桌面 Chrome/Edge -> 访问现有 Linux 服务器上的教学网页 -> 默认打开几行单元的编排教学场景 -> 二维/三维并排查看 -> 选中单元/引脚/网络，联动资料与局部结构 -> 展示性拆解/剖切 -> 切换真实 SKY130 数据通路案例 -> 查看已有阶段和参数对照 -> 修改允许参数并点击运行 -> 等待 ORFS，查看本次结果及前后变化。

此路径中的“编排教学场景”“真实 ORFS 结果”和“展示性拆解”始终有明确来源和状态。首版没有答题、测验、评分、自定义设计上传或故障编辑。

## 5. 实施前尚需明确的技术事项

- 现有 Linux 环境的工具/工艺版本、资源、路径、执行入口与许可证。
- SKY130 首批单元、资料齐备性、晶体管/网络/几何映射与三维尺寸依据。
- 数据通路位宽、具体逻辑、规模与对照案例，保证可读性与可观察性。
- 核心参数有效范围、默认值、配方顺序、规则覆盖与阶段产物。
- 参考桌面电脑与浏览器条件，据此定义帧率、加载与操作验收值。
- 后端框架、数据契约、未来目录约定与第一阶段文件清单。

这些事项通过技术核验和具体实施方案解决。已完成的 WSL 环境检查见 `ORFS_SCAN.md`，它不替代目标 Linux 服务器的核验；具体流程、数据通路规模和三维重建依据仍需后续落实。
