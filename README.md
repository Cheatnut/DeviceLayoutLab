# DeviceLayoutLab

独立的后端物理实现教学项目，通过器件、单元、工艺库、版图和电路的联动展示，帮助学生理解数字集成电路物理设计。

当前阶段：Windows 侧开发并通过 SSH 推送 GitHub，本机 WSL 家目录中的独立 clone 拉取后运行，通过 Windows 浏览器 localhost 查看。远程服务器部署留待后期。已实现二维/三维教学工作台、案例 API、source shell 配置、只读环境检查和真实 LEF/Liberty 资料读取；未执行真实 ORFS 设计流程或生成 Blender 模型。

已确认方向：面向课堂和自主探索；覆盖平面 MOS、FinFET、GAA；采用 Blender + Three.js；前端教学网页、独立后端调用 ORFS，后期接入 Agent，不连接同级教学平台。重心是认识工艺库、标准/物理单元、金属层、走线、闩锁与天线效应；暂不做空间电场求解。

产品形式：工程工作台为主，配预设案例；用户直接选择、操作、运行与对比，不包含答题、测验或评分。

已逐项确认首版产品取舍：桌面 Chrome/Edge、二维/三维上下排列、局部版图、双轨预设案例、三类教学结构、SKY130 首条真实闭环、个人提交、少量参数与专项配方、预先真实运行加按需重跑，以及现有 Linux 服务器部署。后期 Agent 优先场景操控与对象讲解，通过用户密钥调用 API。

开发切片一：在右上角先选择 `局部标准单元行`，再选择独立的 `INV` 或 `NAND2` 教学案例，在二维和 Three.js 三维间联动选择对象，按图层筛选，使用三维图标工具栏观察结构。当前已取消拆解滑块。`ORFS 设计` 类别保留待接入的数据通路案例，运行接口不会伪造工具结果。

INV/NAND2 当前采用纯教学 CMOS 几何，四张卡片依次显示单元版图、棍图、保持器件位置的电路和标准串并联电路，上方显示逻辑式。场区用深蓝虚线、有源区用深蓝实线；P 衬底、N 阱、PAA/NAA、栅氧、多晶硅、接触孔和 M1 使用统一色表。VDD/GND/Y 同属 M1，以标签区分网络。点击 MOS 符号可联动对应栅区及对象资料。

平面坐标、连接、颜色与教学层高集中在 `backend/data/cases.json`，后端生成二维/三维共享几何。三维显示场氧窗口、源漏区、栅氧、多晶硅、接触柱和 M1；栅下保留沟道位置。当前教学模型不使用真实工艺尺寸，也不表示已完成 LVS、DRC 或物理仿真。图层开关作用于版图、棍图和三维；两张电路图始终显示完整拓扑。

在 Linux 或 WSL 的 Bash 终端中加载配置脚本后启动：

```bash
source config/server.local.sh
"$DLL_PYTHON" -m backend.app
```

按脚本中的地址和端口在桌面 Chrome/Edge 打开服务。首次部署从 `config/server.example.sh` 复制为 `config/server.local.sh`，填写后 source。详细 Linux 部署说明见 [deploy/README.md](deploy/README.md)。

工艺库读取能力仍保留在后端，能够读取配置登记的实际库文件；六个 SKY130 单元已在 WSL 的真实资产上验证读取。当前工作台暂不显示工艺库浏览入口。局部三维仍为教学抽象，真实 GDS 内部结构和 ORFS 参数实验是后续切片。

工作台操作：左侧按固定顺序选择 11 个教学对象，点击箭头或按 Ctrl+B 收起/展开（输入框中保留编辑快捷键）；右侧查看对应说明。逻辑标题右侧可播放、重来、暂停和逐步切换：01 单元版图与 02 棍图每秒渐显一组对象，说明随当前对象更新；手动选择或切换案例结束演示。二维在上、三维在下，普通滚轮滚动页面；在三维画布内按住鼠标中键拖动可环绕观察，左键选中对象。

右侧说明栏也可通过标题旁箭头收起/展开。页面收到 Ctrl+L 时切换右栏；部分浏览器会优先用该组合键定位地址栏，此时使用箭头按钮。左右栏采用约 200ms 的宽度和内容过渡，遵从系统“减少动态效果”设置；两侧可独立或同时收起。

三维右上角工具栏按顺序为：复原视角、固定页面、显示网格、显示文本，悬停可查看名称。复原按完整结构范围重新居中取景。固定后画布滚轮控制远近，按 Esc 或再次点击图钉恢复页面滚动；固定图标会竖起。默认有网格和对象标注；图层隐藏时对应标注一同隐藏。
